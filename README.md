# StudyTrack

A Flutter Study Session Log application using SQLite.

## About the Application

StudyTrack is a mobile application that helps students record and manage their study sessions.

## Features

- Add new study session records.
- View saved study session details.
- Edit existing study sessions.
- Delete study session records.
- Validate required form fields.
- Store records locally using SQLite.
- Display up to 10 records per page.
- Navigate between pages.

## Technologies Used

- Flutter
- Dart
- SQLite
- sqflite

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `flutter pub get`.
5. Connect an Android device or start an emulator.
6. Run `flutter run`.
